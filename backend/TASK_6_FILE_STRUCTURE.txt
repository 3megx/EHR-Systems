INTEGRATION POINTS:
==============================================================================

1. MediatR Pipeline (CachingBehavior)
   - Automatically caches queries implementing ICachedQuery
   - No code changes needed in query handlers
   - Applied globally to all queries

2. Command Handlers (Cache Invalidation)
   - After SaveChangesAsync(), call cache invalidation
   - Use CacheInvalidationBuilder fluent API
   - Example: await _cache.InvalidatePatientCacheAsync(patientId)

3. Kafka Event Consumers
   - CacheInvalidationEventHandler subscribes to events
   - Handles: PatientUpdated, SoapNoteCreated, VitalsUpdated, etc.
   - Automatically clears affected caches across all services

4. Health Checks Endpoint
   - /health/cache returns Redis status
   - Included in overall application health
   - Used by: Load balancers, orchestration platforms, monitoring

5. Dependency Injection
   - All services auto-registered in Program.cs
   - Uses builder.Services.AddEHRCommon()
   - Configuration via environment variables or appsettings

USAGE EXAMPLES:
==============================================================================

1. AUTOMATIC QUERY CACHING (Simplest)
   ---
   public class GetPatientQuery : IQuery<PatientDto>, ICachedQuery
   {
       public Guid PatientId { get; set; }
       public string CacheKey => $"patient:{PatientId}";
       public TimeSpan? Duration => TimeSpan.FromMinutes(15);
   }
   
   var patient = await mediator.Send(new GetPatientQuery { PatientId = id });
   // CachingBehavior handles everything!

2. MANUAL GET/SET
   ---
   await _cache.SetAsync("patient:123", patientDto, TimeSpan.FromMinutes(15));
   var result = await _cache.GetAsync<PatientDto>("patient:123");

3. GET OR SET (Prevents thundering herd)
   ---
   var patient = await _cache.GetOrSetAsync(
       CacheKeyGenerator.PatientKey(id),
       async _ => await _repository.GetByIdAsync(id),
       CacheTTLPolicy.MediumLived
   );

4. PATTERN-BASED INVALIDATION
   ---
   await _cache.RemoveByPatternAsync("patient:*");  // Clear all patient caches
   var removed = await _cache.RemoveByPatternAsync("patient:123:*");  // Result: 7 keys

5. EVENT-DRIVEN INVALIDATION (Kafka)
   ---
   await _handler.HandlePatientEventAsync("PatientUpdated", patientId);
   // Automatically clears affected caches across all services

6. BATCH OPERATIONS (Pipeline)
   ---
   var keys = new[] { "patient:123", "patient:456", "patient:789" };
   var patients = await _cache.GetManyAsync<PatientDto>(keys);
   // Single Redis pipeline request, not 3 separate calls

7. HEALTH CHECKS
   ---
   app.MapHealthChecks("/health/cache");
   // GET /health/cache returns Redis connectivity status + metrics

Query Parameters:
  ICachedQuery.CacheKey          → "entity:id:detail"
  ICachedQuery.Duration          → TimeSpan or null

Cache Operations:
  GetAsync<T>(key)               → Retrieve or null
  SetAsync<T>(key, value, ttl)   → Store with optional TTL
  RemoveAsync(key)               → Delete single
  RemoveByPatternAsync("key:*")  → Bulk delete by pattern
  GetOrSetAsync(key, factory)    → Atomic get-or-load
  ExistsAsync(key)               → Check presence
